# RadiologyOS Project Memory

Ця папка містить узгоджені правила, структуру та операційну пам'ять проєкту RadiologyOS.

## Джерела

Документація сформована на основі:

- поточного вебсайту RadiologyOS;
- коду `radiologyos-site-v22`;
- публічних сторінок `index.html`, `about.html`, `price.html`, `military.html`, `cabinet.html`;
- внутрішньої панелі `staff.html`;
- модулів `cart.js`, `department.js`, `notify.js`, `pricelist.js`, `qrgen.js`, `slots.js`;
- Google Apps Script інтеграції;
- погоджених бізнес-процесів відділення променевої діагностики.

## Документи

- `design-system.md` — кольори, типографіка, відступи, компонування.
- `components.md` — каталог повторно використовуваних компонентів.
- `copywriting.md` — правила текстів і термінології.
- `pages.md` — карта публічних і внутрішніх сторінок.
- `seo.md` — SEO-правила публічної частини.
- `changelog.md` — історія змін продукту.
- `lessons.md` — зафіксовані рішення та помилки, які не можна повторювати.
- `domain-model.md` — сутності системи й зв'язки.
- `roles-permissions.md` — ролі та права доступу.
- `workflows.md` — основні робочі процеси.
- `mvp-roadmap.md` — склад MVP і дорожня карта.
- `AGENTS.md` — обов'язкові правила для Codex та інших AI-агентів.
