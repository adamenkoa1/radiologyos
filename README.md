# radiologyos.tech — сайт відділення променевої діагностики

Цей репозиторій оновлюється **автоматично** сервером відділення (проєкт radiology-next):
коли в CRM змінюються ціни, графік роботи або тексти сайту, сервер робить знімок сайту
(`public/`) і надсилає його сюди. GitHub Actions (`.github/workflows/deploy.yml`) публікує його
на Cloudflare (radiologyos.tech).

- `public/` — сторінки сайту і їхні файли; `public/snapshot/api/*.json` — ціни, години, тексти.
- `worker/index.js` — Cloudflare Worker: віддає сторінки, а живі частини (вільні години,
  збереження заявки, статистика відвідувань) передає на сервер відділення через Cloudflare Tunnel.
  Якщо сервер недоступний — сайт працює, заявку пацієнт надсилає в месенджер.
- Вхід персоналу (CRM) — https://radiologyos.tech/login: Worker передає кабінет на сервер відділення
  через той самий тунель (за паролем). Сервер недоступний — сторінка «кабінет недоступний».

Не редагуйте файли тут вручну — наступний знімок їх перезапише. Джерело: radiology-next,
`scripts/export-site.mjs` і папка `edge/`.

Попередня версія (застосунок RadiologyOS на Next.js, D1, R2) збережена в гілці `legacy-app`.
Повернути її: в Actions запустити її `deploy.yml` або злити гілку назад у `main`.
