# RadiologyOS Pages Map

## 1. Поточна публічна частина

### `/site/` або `index.html`
Головна сторінка.

Блоки:
- госпіталь;
- відділення;
- для військовослужбовців;
- для цивільних;
- послуги;
- тарифи;
- онлайн-заявка;
- контакти;
- вхід.

### `about.html`
Про відділення.

Блоки:
- дослідження;
- обладнання;
- персонал;
- графік;
- звернення та відгуки;
- офіційні канали НСЗУ.

### `price.html`
Прайс-лист.

Функції:
- групи послуг;
- описи;
- ціни;
- додавання до кошика;
- перехід до заявки.

### `military.html`
Сторінка для військовослужбовців.

Блоки:
- безоплатні дослідження;
- порядок проходження;
- планові/екстрені дослідження;
- отримання результатів.

### `cabinet.html`
Демонстраційний кабінет пацієнта.

Важливо:
- на Web MVP не є захищеним медичним кабінетом;
- не зберігати реальні дані.

## 2. Поточна внутрішня частина

### `staff.html`
Фактично містить кілька модулів в одному файлі:

- заявки;
- черга на сьогодні;
- розклад;
- прайс;
- відділення;
- комунікації та оплата;
- налаштування;
- редагування персоналу;
- редагування обладнання;
- редагування текстів сайту;
- протоколи;
- синхронізація Google Apps Script.

## 4. Доступ за ролями

- Dashboard: завідувач, старший рентгенлаборант, адміністратор.
- Applications: реєстратор, адміністратор.
- Schedule: реєстратор, старший рентгенлаборант, лікарі, лаборанти.
- Patients: реєстратор, лікарі, дозволений персонал.
- Protocols: лікар-рентгенолог, лікар УЗД.
- Equipment: старший рентгенлаборант, інженер, адміністратор.
- Inventory: старший рентгенлаборант, медична сестра.
- Reports: завідувач, адміністратор.
- Settings: системний адміністратор.

## 5. SEO

- Публічні сторінки індексуються.
- `staff`, `cabinet`, службові сторінки — `noindex,nofollow`.
