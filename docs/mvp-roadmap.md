# RadiologyOS MVP and Roadmap

## RadiologyOS 1.0 — Web MVP

### Входить

- публічний сайт;
- військовий і цивільний маршрути;
- прайс;
- заявка;
- CRM заявок;
- календар відділення;
- кабінети й обладнання;
- базова картка пацієнта;
- дослідження;
- ролі;
- панель персоналу;
- базові протоколи;
- оплата;
- базові звіти;
- тестові дані;
- адаптація під планшет.

### Не входить

- реальна медична база;
- DICOM;
- Orthanc;
- справжня серверна авторизація;
- зберігання медичних файлів;
- КЕП;
- повноцінна офлайн-мережа.

## RadiologyOS 2.0 — локальна система

- локальний сервер;
- PostgreSQL;
- REST API;
- багатокористувацька робота;
- серверна авторизація;
- журнал дій;
- резервні копії;
- Orthanc;
- DICOM;
- склад;
- обладнання;
- розширені звіти;
- робота без Інтернету в локальній мережі.

## RadiologyOS 3.0 — платформа

- AI-помічник;
- голосова диктовка;
- AI-конструктор протоколів;
- контроль якості;
- телерадіологія;
- HL7/FHIR;
- мультизакладність;
- SaaS-модель;
- мобільний застосунок.
