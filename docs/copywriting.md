# RadiologyOS Copywriting Guide

## 1. Мова

Основна мова інтерфейсу — українська.

Технічні англійські терміни допускаються лише у документації або коли немає усталеного українського відповідника.

## 2. Тон

### Для пацієнта
- спокійний;
- зрозумілий;
- без залякування;
- без зайвої медичної термінології;
- без гарантій результату.

### Для персоналу
- короткий;
- операційний;
- однозначний;
- із чіткою дією.

## 3. Погоджені назви

Писати:

- Відділення променевої діагностики.
- КТ.
- Рентгенографія.
- Флюорографія.
- Пантомографія.
- УЗД.
- Рентгенлаборант.
- Старший рентгенлаборант.
- Лікар-рентгенолог.
- Лікар УЗД.
- Медична сестра.
- Санітарка.
- Реєстратор.
- Внутрішньовенне контрастування.
- Календар відділення.
- Пацієнт прибув.
- Розпочати дослідження.
- Завершити дослідження.

Не писати:

- Мамографія, якщо модуль не погоджено.
- Старша медична сестра.
- Оператор рентгену.
- Клієнт.
- Процедура замість дослідження, коли йдеться про діагностичне дослідження.

## 4. Кнопки

Добре:

- Записатися.
- Подати заявку.
- Підтвердити запис.
- Зберегти.
- Скасувати.
- Пацієнт прибув.
- Розпочати.
- Завершити.
- Перенести.
- Надіслати повідомлення.

Уникати:

- ОК.
- Так.
- Продовжити — без уточнення, що саме відбудеться.
- Відправити — коли правильніше «Надіслати».

## 5. Помилки

Формула:

1. Що сталося.
2. Що робити далі.

Приклад:

> Заявку не вдалося передати онлайн. Дані збережені лише в цьому браузері. Зателефонуйте до реєстратури.

## 6. Медичні попередження

- Не давати діагностичних обіцянок.
- Не замінювати консультацію лікаря.
- Для контрасту чітко вказувати підготовку.
- Невідкладні винятки підтверджує лікар-рентгенолог.

## 7. Заголовки

- Один H1 на сторінку.
- Заголовок описує дію або зміст.
- Не використовувати рекламний клікбейт.
