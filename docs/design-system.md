# RadiologyOS Design System

## 1. Принципи

RadiologyOS має виглядати як спокійна, професійна медична система:

- висока читабельність;
- великі зони натискання;
- мінімум декоративного шуму;
- чіткі статуси;
- стабільна навігація;
- однакова поведінка на комп'ютері й планшеті.

:root {

## 3. Кольори модальностей

- КТ — зелений/бірюзовий.
- Рентгенографія — синій.
- Флюорографія — жовтий.
- Пантомографія — фіолетовий.
- УЗД — помаранчевий.

Колір модальності не повинен замінювати текстову назву.

## 4. Типографіка

Основний шрифт:

```css
font-family: Inter, system-ui, -apple-system, "Segoe UI", sans-serif;
```

Рекомендовані розміри:

- H1: 30–36 px.
- H2: 22–28 px.
- H3: 18–22 px.
- Основний текст: 15–17 px.
- Допоміжний текст: 12–14 px.
- Табличні дані: не менше 13 px.

## 5. Відступи

Базова шкала:

```text
4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48
```

Не використовувати випадкові значення без потреби.

## 6. Радіуси

- Великі панелі: 20–24 px.
- Картки: 14–18 px.
- Поля: 10–12 px.
- Кнопки: 10–14 px.
- Badge: 999 px.

## 7. Тіні

Тіні мають бути слабкими:

```css
box-shadow: 0 10px 30px rgba(16, 32, 36, 0.08);
```

## 8. Кнопки

Варіанти:

- Primary.
- Secondary.
- Ghost.
- Danger.
- Icon button.

Мінімальна висота кнопки на планшеті — 44 px.

## 9. Форми

- Label завжди видимий.
- Placeholder не замінює label.
- Помилка показується біля поля.
- Обов'язкові поля позначаються текстом або `*`.
- Телефон форматується для України.
- Дата народження не може бути в майбутньому.
- Для цивільного онлайн-запису діє обмеження 18+.

## 10. Таблиці

На комп'ютері:

- sticky header;
- пошук;
- фільтри;
- сортування;
- горизонтальна прокрутка лише як резерв.

На планшеті:

- картковий режим замість дуже широкої таблиці;
- основні дії доступні без hover.

## 11. Календар

Орієнтир — Google Calendar:

- День / Тиждень / Місяць;
- кнопка «Сьогодні»;
- попередній/наступний період;
- шкала часу;
- колонки днів або кабінетів;
- картки записів;
- drawer праворуч;
- drag & drop — після стабілізації базової логіки.

## 12. Доступність

- Контраст тексту не нижче WCAG AA.
- Не покладатися тільки на колір.
- Видимий focus.
- Клавіатурна навігація.
- `aria-label` для іконок.
