# RadiologyOS SEO Rules

## Область застосування

SEO використовується лише для публічних сторінок.

Не індексувати:

- `/staff`;
- `/cabinet`;
- внутрішні маршрути;
- сторінки з персональними даними;
- службові сторінки;
- тестові сторінки.

## Технічні вимоги

Кожна публічна сторінка повинна мати:

- унікальний `<title>`;
- унікальний meta description;
- canonical;
- Open Graph;
- favicon;
- `lang="uk"`;
- коректну ієрархію H1–H3;
- sitemap;
- robots.txt.

## URL

Перевага коротким зрозумілим URL:

```text
/site/
/site/about/
/site/military/
/site/prices/
/site/ct/
/site/xray/
/site/fluorography/
/site/pantomography/
```

## Локальне SEO

Ключові сутності:

- Чернігів.
- Чернігівський військовий госпіталь.
- Відділення променевої діагностики.
- КТ у Чернігові.
- Рентген у Чернігові.
- Флюорографія у Чернігові.
- Пантомографія у Чернігові.

Не перевантажувати сторінки ключовими словами.

## Медичний контент

- Автор/відповідальний лікар.
- Дата оновлення.
- Джерела для медичних рекомендацій.
- Чітке розмежування інформації та медичної консультації.
- Не обіцяти діагноз або результат.

## Schema.org

Можливі типи:

- `MedicalOrganization`;
- `Hospital`;
- `MedicalClinic`;
- `Physician`;
- `Service`;
- `FAQPage`;
- `BreadcrumbList`.

Перед публікацією перевірити відповідність фактичним даним.
